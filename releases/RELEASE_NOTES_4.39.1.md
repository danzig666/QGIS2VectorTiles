**QWebMap 4.39.1**

QWebMap started as a fork of [GallPeters/QGIS2VectorTiles](https://github.com/GallPeters/QGIS2VectorTiles) by Jossef Kanter. It is not an official release of the original plugin, and it installs next to it.

This is the **generic** edition — the one to download. (A special Hungarian zoning-plan edition, not for general use, is released separately with a `-hu` tag.)


### Changed
- **The repository is renamed to QWebMap:** <https://github.com/danzig666/QWebMap>. The plugin's homepage, issue tracker and changelog links point there, and the live demo is at <https://danzig666.github.io/QWebMap/>. Old links (repository, releases, downloads, the demo and embedded demo maps) still forward to the new addresses. Nothing else changed.
