about=QWebMap turns a QGIS project into a public web map that looks like it does in QGIS. Its core is an accurate converter of QGIS symbology to vector tiles and a MapLibre style: categorized, graduated and rule-based renderers, hatches, point/SVG pattern fills, gradient and shapeburst fills, marker lines at the QGIS positions, dashes, arrows, SVG and font markers, and labels in your own fonts; what the browser cannot draw natively is rendered by QGIS into sprites or pre-computed geometry, and every export writes a fidelity report. Its Publish Web Map window builds vector tiles in one PMTiles archive (QGIS-accurate styling: marker-line positions, patterns, dashes, labels, with a fidelity report), raster layers as image tiles, an optional OpenStreetMap vector basemap or web (XYZ) basemaps, map themes as views and a full modern viewer (layers, legend, popups, search, filters, permalinks, measuring with snapping, printing). It publishes with verification to Cloudflare R2 or other S3-compatible storage at a stable address, and keeps all settings in the project. No map server needed. QWebMap started as a fork of QGIS2VectorTiles by Jossef Kanter (https://github.com/GallPeters/QGIS2VectorTiles); its Processing tool still exports a static vector tile package.
